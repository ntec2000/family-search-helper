# 世 차이를 이용한 출생 연도 추정

## 계산

같은 시조·같은 기준으로 아래로 증가하는 世 번호를 확인한 경우에만 다음 모델을 사용한다.

`대상 추정 출생년 = 기준 인물의 확인된 출생년 + (대상 世 - 기준 世) × 가정한 세대 간격`

- 기본 세대 간격: 30년. 기존 서비스의 입력 허용 범위 20~40년을 유지한다. 이 범위는 모델 입력 제한이며 역사 통계나 신뢰구간이 아니다.
- 기준 인물은 조상이나 후손 모두 가능하다. 10世 1650년을 기준으로 7世를 계산하면 about 1560, 13世는 about 1740이다.
- 28년을 가정하면 같은 7世의 추정값은 about 1566이다. 평균의 선택에 따라 결과가 달라진다.
- 1世부터 25世까지의 간격은 24세대다. 世孫·代孫·자신부터 위로 센 번호를 이 世 번호와 자동 혼합하지 않는다.
- 특정 가문의 ‘세손=세’ 또는 ‘세손=세-1’을 일률적으로 확정하지 않는다. 사용자가 동일 기준을 확인해야 한다.
- 기준·계산 결과 서기는 1~9999 범위여야 한다. 근거가 없거나 범위를 벗어나면 제안하지 않는다.

## 화면과 원문 보존

인물 작업 메뉴 → 만세력 출생 연도 추정 → 세대 차이로 출생 연도 추정.

1. 기준 인물의 확인된 **출생년**, 기준 世, 대상 世, 세대 간격, 기준 인물·출처를 입력한다.
2. 동일한 시조·世 계산 기준임을 확인한다. 출처나 기준이 없으면 승인할 추정값을 만들지 않는다.
3. 간지 생년이 있으면 모델값 근처의 만세력 후보를 대조한다. 같은 거리 후보는 자동 선택하지 않는다. 검토자가 후보를 직접 선택한 경우 근거에 남긴다.
4. 간지가 없는 경우에는 세대 모델값 자체를 ‘약 YYYY년 (about YYYY)’으로 제시할 수 있다.
5. 승인하면 about YYYY로 결과 후보에 반영하고 기준 출생년·두 世 번호·세대 간격·출처·간지/직접 선택 여부를 근거에 기록한다. 기존 원문과 원본 인물 객체는 보존한다. 실제 저장은 기존 검토 완료 흐름을 따른다.
6. 세대 모델은 출생 연도용이다. 이를 사망 연도로 사용하지 않는다. 기존에 입력한 확정 날짜는 이 기능으로 덮어쓰지 않는다.

## 정확도와 자료 해석

- 30년은 사용자 선택 가정이다. ‘가장 널리 쓰임’, 평균 28~31년, 장남/차남의 고정 평균 등의 통계는 이번에 확인하지 못했으므로 제품의 사실 안내로 채택하지 않는다.
- ±5년 또는 ±10년 오차를 보장하지 않는다. 세대가 멀어질수록 모델 오차가 누적될 수 있다.
- 과거 급제년·묘비 건립년·사망년은 출생년이 아니다. 생년으로 사용하려면 별도 자료 해석이 필요하다.
- 간지가 맞는 가장 가까운 후보도 실제 출생년의 확정 증거는 아니다. 모델값과 간지 원문, 다른 가족의 연대 기록을 함께 검토한다.
- 갑자는 첫 번째, 임진은 29번째이므로 갑자년에서 임진년은 28년 뒤이다. 예: 1924 갑자 → 1952 임진. 8년 뒤인 1932는 임신이다.
- 1892년은 조선 고종 29년이다. 임진년 후보에는 1592·1652·1712·1772·1832·1892·1952·2012 등이 있다.
