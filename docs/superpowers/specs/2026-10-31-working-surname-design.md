# 족보 작업 성씨와 가족 이름 규칙

사용자 지시: 분석 전에 문중 성씨를 자동 감지하거나 한글로 직접 입력한다. 본손 아들·딸에만 적용하며 이름 없는 딸은 성씨 표시명(이씨), 아내는 본관을 제외한 성씨(변씨)로 표시한다. 사위 이름은 별도로 유지하고 사위 부친의 성씨가 생략된 경우 사위 성을 조합한 후보를 표시한다.

기존 Flutter 입력창·파서·표시 도구를 확장한다. 새 외부 서비스나 DB 이관은 사용하지 않는다. 별도 성씨 화면 신설보다 기존 입력창과 촬영 화면의 사전 입력 버튼을 재사용하는 방식으로 구현한다.

구현 판단: 자동 감지는 OCR 텍스트를 얻은 뒤 인물 파싱 전에 확인한다. 한글만 제출해도 되며 한자 선택은 선택 사항이다. 수동 성씨는 자동 감지 결과보다 우선하고, 다른 문중의 한자 성을 섞지 않는다. 미감지·상충은 자동 확정하지 않고 직접 입력한다.

女 순번은 작업 성씨가 확인된 현재 분석 쪽의 등장 순서에 따른 작업 표시다. 첫째딸·둘째딸로 표시하되 명시된 원문 서수는 유지하고, 실제 출생순서 및 부모 ID를 자동 확정하지 않는다. 성씨가 없는 일반 파싱의 기존 미상 표시는 유지한다.

완성 성함은 성과 개인 이름을 조합해 표시한다. 이름 미상 표시명을 개인의 실제 이름이나 새 가족 인물로 만들지 않는다. OCR 원문·원본 파일·사위 이름·기존 저장 자료는 보존하며 기존 기록에 소급 적용하지 않는다.
