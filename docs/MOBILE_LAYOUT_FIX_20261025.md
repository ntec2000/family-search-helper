# 모바일 화면 넘침 및 스크롤 수정

사용자 실기기 사진의 RIGHT/BOTTOM OVERFLOW 줄무늬는 레이아웃 오류 표시다.
원본 족보 이미지가 변형되거나 새로운 이미지가 생성된 현상은 아니다.

## 원인과 수정 (B)

- 결과 화면의 고정 Column에 긴 안내·관계 확인·탭을 모두 넣어 큰 글씨에서 목록 높이가 사라졌다.
  NestedScrollView로 안내와 조작 영역을 스크롤하며 인물/원문/이미지 탭은 고정했다.
- 저장 버튼을 겹쳐 표시하던 FAB에서 별도 하단 영역으로 옮겼다. 기존 저장 검증은 유지한다.
- 홈 배너는 Wrap으로 줄바꿈하며 빈 목록의 소개 영역도 스크롤한다.
- 인물 세대 제목과 인원수도 가용 폭 안에서 줄바꿈한다.
- Flutter 웹에서 상단 아이콘의 긴 도움말이 투명한 여러 줄 터치 영역으로 늘어나 탭을 가리던 문제를
  `성씨 입력`, `제외 복원`의 짧고 명확한 도움말로 해결했다.
- 인물·관계·원문·DB 스키마와 사용자 데이터는 변경하지 않았다.
