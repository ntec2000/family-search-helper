# 통합 앱의 배포 대상

사용자 결정: Android 네이티브 앱 + PC·아이폰 공용 웹앱.

- 공통 Flutter 소스 `lib/`의 화면·모델·인물 검토·관계 검토·저장·내보내기를 공유합니다.
- 안드로이드: 기존 APK와 온디바이스 ML Kit 경로를 유지합니다.
- 아이폰: Safari로 웹앱을 열고 필요하면 공유 메뉴에서 홈 화면에 추가합니다.
- 웹: 기존 Flutter 웹 빌드를 사용합니다. 홈 화면 아이콘은 기존 Android 브랜드 아이콘을 재사용합니다.
- 이전에 추가한 `ios/` 소스는 보존하지만 운영·배포 대상에서 제외하며 iOS 전용 CI는 비활성화합니다. Apple 서명 작업을 진행하지 않습니다.
- PC 로컬 실행용 Python/RapidOCR 패키지는 PC에서 사용하는 선택 경로입니다. 아이폰에서 ZIP이나 Windows cmd를 실행하는 방식이 아닙니다.
- 아이폰에서 사용하려면 접근 가능한 웹 호스팅 주소가 필요합니다. 현재 코드 변경만으로 공개 배포 URL이 생성되지는 않습니다.
- 기기별 로컬 데이터는 자동 동기화되지 않습니다. 사진/PDF/OCR/저장과 Safari 홈 화면 동작의 실기기 검증은 별도입니다.
