# 출처를 확인한 족보 판독 규칙

## 출계 표기

- 경상남도교육청 김해도서관의 족보 해설은 出后·出繼를 다른 집으로 양자로 간 표기로 설명한다. 系子·繼子는 양자로 들어온 경우의 표기로 구별한다.
  출처: https://ghlib.gne.go.kr/menu.es?mid=a30307020000
- 뿌리를 찾아서는 出系·出后를 출계 표기로 설명한다.
  출처: https://www.rootsinfo.co.kr/info/board/index.php?Md=body&board=guest_board&key=&keyfield=subject&n=2559&pages=19
- 구현 범위: 본인 기록의 出系·出后·出繼를 메모에 보존하고 관계 검토 대상으로 표시한다. 대상이나 친생·양부모가 명확하지 않으면 추정하거나 자동 연결하지 않는다. 배우자 기록 안의 표기는 본인에게 옮기지 않는다.
- 系子·繼子는 양자로 들어온 표기 후보로 메모에 남기고 출계와 구분한다. 생부·양부는 원문과 사용자 검토 없이 자동 연결하지 않는다.
- 사용자 제공 네이버 블로그 저장본 「족보 보는 법」도 출후·출계와 계자를 구분한다. 첨부 원문: https://m.blog.naver.com/hankng/222486353569
- OCR 출력은 후보이며 모든 표기와 소속은 원문 대조가 필요하다. 같은 족보라도 편찬 시기와 문중에 따라 기재 방식이 다를 수 있다.

## 世와 世孫·代孫

- 사용자 제공 대이음 자료는 世孫·代孫의 셈법이 가문마다 다를 수 있으므로 족보 범례를 확인하도록 안내한다. https://www.daeium.com/blog/how-to-read-jokbo
- 다른 첨부 자료는 世孫과 代孫의 셈법을 서로 다르게 설명한다. 따라서 世孫·代孫·世祖·代祖를 世 값으로 자동 변환하지 않고 원문과 기준 확인 필요 메모를 보존한다. 명시적인 世 표기는 별도로 읽는다.
- 이름의 항렬자나 세대 번호만으로 부모 관계 또는 생년을 확정하지 않는다.

## 족보의 시대별 표기

- 성균관대학교 한국족보자료시스템은 안동권씨 성화보의 사위 표기로 女夫가 사용되었으며 前夫·後夫도 나타난다고 설명한다. https://jokbo.skku.edu/intro/jokbo_story.jsp
- 女夫는 딸 표기 女 뒤의 이름으로 자동 확정하지 않고 미분류 원문으로 남긴다. 대상 딸과 배우자 관계는 사용자가 원문을 확인한다. 前夫·後夫, 室·娶는 족보별 맥락이 필요하며 현재 별도의 자동 관계 추출을 보장하지 않는다.

## 생부 표기

- 사용자가 제공한 족보 해설 저장본은 양자로 들어온 인물에 생부(生父)를 별도로 표기한 사례를 설명한다. https://2642415.tistory.com/m/7723354
- 본인 기록의 生父는 검토 메모로 알리고 원문을 보존한다. 생부·양부의 이름과 연결은 문맥과 사용자 확인 없이 추정하지 않는다.

## 기일 표기

- 정월·윤달과 初 등의 월일 표기는 족보 날짜 해설에서도 확인된다. https://jaturitube.tistory.com/502 및 https://historygogo.com/guide/jokbo-hanja-terms/
- 본인과 배우자의 忌 월일에서 정월·윤달 등 원문을 보존한다. 연도 없는 기일만으로 서기 연도를 정하거나 양력으로 변환하지 않는다. 사망일과 제사일의 관계는 원문과 가문 관례를 확인한다.

## 계자 이름 표제

- 대보사 족보보는법 저장 자료는 계자(系子) 뒤에 입양 인물의 이름을 적고 생부를 표시하는 사례를 안내한다. http://www.daebosa.co.kr/html/07/07.php
- 독립 구획의 시작에 系子·繼子와 이름이 함께 있을 때 인물 후보와 입양 검토 메모를 만든다. 인물 중간의 계자 표기는 새 인물로 자동 분리하지 않는다. 이름이 누락되거나 표제가 애매하면 원문 검토 대상으로 남긴다.

## 본명과 별도 이름

- 사용자 제공 「족보에 올린 이름」은 일상에서 쓰는 이름과 족보에 올린 이름이 다른 개인 사례를 설명한다. https://brunch.co.kr/@yjehong/55
- 初名·初諱·一名·兒名·異名 뒤 이름은 문맥이 분명한 경우에만 본인의 별도 이름 후보 메모로 남긴다. 본명을 교체하거나 서로 다른 인물을 자동 병합하지 않는다. 배우자 기록의 별도 이름은 본인에게 붙이지 않는다.

- 初諱는 처음에 쓰던 이름을 뜻하는 표기로 설명된다. 사용자 제공 용어 자료: https://historygogo.com/guide/jokbo-hanja-terms/
