# 추정 서기 표시와 가족 참고

- 사용자 요청: 임진년 등의 간지를 약 YYYY년으로 표시하고 아버지·아들·딸을 참고란에 정리한다.
- 기존 기능: 검토자가 근거 기준 연도를 입력하고 만세력 후보를 승인하면 about YYYY로 저장한다. 1700년 이전 후보 제한을 1000~2100년으로 넓힌다.
- 표시: about 1592는 약 1592년 (about 1592)으로 출력한다. 원래 간지와 판단 근거는 보존한다. 기준 연도 없이 특정 서기를 고르지 않으며 미선택 상태를 표시한다. 간지의 60년 반복 때문에 1600년은 모든 임진년의 실제 연도가 아니다.
- 예시(기능 검증용, 특정 인물 생년 아님): 壬辰年 生, 기준 1600 → about 1592. 기준 1622이면 1592·1652와 같은 거리라 자동 선택하지 않는다.
- 가족 참고: 앱에 저장된 부친 ID와 자녀의 부모 ID를 사용한다. 이름 없는 딸은 성씨·딸 순번·남편명·앱 ID로 구분한다. 앱 ID는 FamilySearch ID가 아니다.
- 조회 불가·중복 ID·성별 오류와 부모 쪽에만 있는 자녀 목록은 확인 필요로 표시한다. 같은 성씨·세대·OCR 등장순서만으로 부모 관계를 생성하지 않는다. 미연결은 가족 없음의 확정이 아니다.
- 기존 날짜·관계·OCR 원문과 DB 스키마는 바꾸지 않는다. 새로운 자동 FamilySearch 전송은 포함하지 않는다.
- 수정 전 CI 41257811998: 340개 통과, 신규 회귀 테스트 3개 실패. 수정 후 CI는 구현 커밋에서 확인한다.
- 근거: 한국학중앙연구원 역법 https://encykorea.aks.ac.kr/Article/E0036603 (60년 반복), 국사편찬위원회 https://contents.history.go.kr/mobile/ta/view.do?levelId=ta_p111r_0010_0150_0180 (1592년 임진).
