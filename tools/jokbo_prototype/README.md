# 우리의 족보 · 로컬 웹 프로토타입

기존 Flutter 앱과 별도로 실행하는 검수용 도구입니다. Python 3과 PATH에 등록한 Tesseract 5가 필요합니다. 저장소의 `web/ocr-models/chi_tra_vert.traineddata`를 사용합니다.

저장소 루트에서 실행합니다.

```sh
python tools/jokbo_prototype/parser_engine.py
```

브라우저에서 **http://127.0.0.1:8765/** 를 엽니다. JPG 또는 PNG를 선택하고 OCR을 실행합니다. 필요하면 세대 구획을 잘라 올립니다.

| 단계 | 처리 |
| --- | --- |
| 이미지 | 브라우저가 같은 PC의 Python 서버에 이미지 바이트를 보냅니다. |
| OCR | Tesseract의 번체 세로쓰기 모델을 호출하고 결과 원문을 돌려줍니다. |
| 파싱 | 줄 앞의 `諱` 또는 `휘`가 있는 이름만 후보로 추출합니다. 한글 독음은 직접 입력합니다. |
| 검수 | 인물별 값을 수정하고 부모 한 명을 직접 선택합니다. 순환 연결은 막습니다. |
| 저장·출력 | 현재 브라우저의 로컬 저장소에 검수본과 원문을 저장합니다. 인쇄 메뉴에서 A4 세로쓰기 또는 PDF 저장을 선택할 수 있습니다. |

`21世 諱 格 壬辰年生`은 세대 21, 한자 이름 格, 생몰 원문 壬辰年生으로 표시합니다. 다른 줄의 문구, 미확인 날짜와 관계는 원문을 보고 입력합니다. 이미지 원본은 사용자가 보관합니다. OCR 원문과 편집본은 **브라우저에 저장**을 누르면 현재 브라우저 프로필에 남습니다. 브라우저의 사이트 데이터를 지우면 삭제됩니다.

모델 출처와 라이선스는 [SOURCE.txt](../../web/ocr-models/SOURCE.txt)에 있습니다. Microsoft Store 제품의 내부 기술은 확인하지 않았습니다.
